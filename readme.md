1. Tujuan
Praktikum ini bertujuan untuk memahami cara menghubungkan CSS eksternal dengan HTML, menggunakan selector dan class, memahami aturan cascade dan specificity, serta mempelajari box model yang terdiri dari content, padding, border, dan margin.

2. Penjelasan Perubahan
Pada praktikum ini dilakukan beberapa perubahan pada halaman formulir dari praktikum sebelumnya perubahan yang dilakukan yaitu menambahkan file style.css dan menghubungkannya dengan index.html, kemudian menambahkan class card pada form dan class notice pada paragraf petunjuk selain itu, dilakukan percobaan pada selector, specificity, warna, padding, border, margin, dan box-sizing untuk melihat pengaruhnya terhadap tampilan halaman.

3. Hasil Uji
Berdasarkan pengujian, stylesheet berhasil terhubung dan perubahan CSS dapat terlihat pada halaman selector dan class dapat diterapkan pada elemen yang sesuai pada pengujian specificity, aturan .card p tetap lebih spesifik dibandingkan notice pada pengujian box model, ukuran elemen berubah dari 276px menjadi 240px setelah menggunakan box-sizing border-box hasil pengujian kemudian diperiksa melalui browser dan DevTools.

4. Batasan
Praktikum ini masih menggunakan halaman formulir sederhana dan pengujian dilakukan pada lingkungan lokal menggunakan browser dan DevTools ukuran tetap pada box model hanya digunakan untuk keperluan eksperimen, bukan sebagai desain akhir selain itu, hasil pengujian yang ditulis dalam laporan harus berdasarkan hasil aktual yang diperoleh saat melakukan praktikum, bukan hanya berdasarkan hasil yang diharapkan pada modul.
